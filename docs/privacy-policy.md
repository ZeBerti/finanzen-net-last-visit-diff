# Privacy Policy

## Finanzen.net Last Visit Diff

This extension processes portfolio information locally in the browser to calculate changes since the last snapshot or visit.

## What data is used

The extension reads information already visible on supported `finanzen.net` depot pages, including:

- portfolio totals
- position names
- current prices
- performance values
- stable position identifiers when available

## What data is stored

The extension stores snapshot data locally in the browser.

This currently includes values such as:

- snapshot key
- position or portfolio name
- current value
- absolute performance
- summed value change
- snapshot timestamp

The stored data is used only to compare the current portfolio view with an earlier snapshot.

## What data is not collected

The extension:

- does not send portfolio data to an external server
- does not use analytics or tracking
- does not sell or share user data
- does not require an account

## Storage location

Snapshot data is stored in the browser on the local device.

## Permissions

The extension currently uses:

- `storage` to persist settings
- `tabs` for popup actions that refresh the current depot tab

## Changes

This policy may be updated if the extension’s storage or permissions change.
